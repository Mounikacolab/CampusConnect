CampusConnect – College Digital Notice Board

Project Description

CampusConnect is a Flutter-based college digital notice board application that allows students to view and access important college announcements.

Objectives

- Provide a centralized platform for college announcements.
- Organize notices according to departments.
- Allow authorized users to publish and manage notices.
- Make announcements easily accessible.

Technologies Used

- Flutter
- Dart
- Provider
- SharedPreferences
- Android Studio
- Visual Studio Code
- Git and GitHub

Features

- Add notices
- View notices
- Edit notices
- Delete notices
- Department-wise filtering
- Notice details
- Local data persistence

Installation

1. Clone this repository:
   "git clone https://github.com/Mounikacolab/CampusConnect.git"

2. Open the project directory:
   "cd CampusConnect"

3. Install dependencies:
   "flutter pub get"

4. Run the application:
   "flutter run"

Android APK

The release APK is generated using:

"flutter build apk --release"
